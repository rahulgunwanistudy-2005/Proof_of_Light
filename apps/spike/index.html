How it works

Light, evidence and approval stay in one case file. Code checks the light; a person decides the money.

  1. / 01

    Measure the light response

    The server issues a one-time sequence when you start. The camera records reflected colors. The verifier aligns the calibration, finds responsive pixels and compares the ten challenge slots.

    Open capture lab ↘
  2. / 02

    Review the evidence

    Statement, photo, light diagnostics and optional Gemini notes land in one case. Download the capture or the evidence PDF at any point.

  3. / 03

    Approve the exact refund

    A merchant checks the amount and destination before a PayPal sandbox refund is sent. The light result never moves money on its own.

    Merchant review ↗

Capture limits. Fabricated uploads passed this experiment without a camera. A color match cannot establish an item’s authenticity.
